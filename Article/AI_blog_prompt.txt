# AI Blog Post Generator Prompt

You are an expert React/Tailwind developer tasked with creating a new blog post for the AutoSpex application.
Your goal is to convert the provided HTML content into a flawless, production-ready React component that strictly adheres to the existing design system.

## Inputs
1.  **Content**: {BLOG_HTML_CONTENT} (The body of the article)
2.  **Images**: {BLOG_IMAGES} (List of image filenames to use)
3.  **Meta**: {FEATURED_IMAGE}, Title, Description, Author, Date.

## Instructions

### 1. File Location & Naming
- Create a new file in `/Article/posts/`.
- Name the file using kebab-case based on the title (e.g., `my-new-post.tsx`).
- **CRITICAL**: The filename and the URL slug will match. The system uses a dynamic loader, so simply creating this file makes it live at `/article/my-new-post`.

### 2. Template Usage
- You MUST wrap the entire content in the `<BlogTemplate>` component.
- Import it: `import BlogTemplate from '../templates/BlogTemplate';`

### 3. Component Structure
```tsx
import React from 'react';
import BlogTemplate from '../templates/BlogTemplate';
// Import images from ../assets/
import img1 from '../assets/YOUR_IMAGE_1.jpg';

// CRITICAL: Export this 'meta' object exactly as shown. 
// This is used by the Blog Index page to automatically list your article.
export const meta = {
    title: "YOUR TITLE", // The headline shown on the page
    seoTitle: "SHORT TITLE", // 47 characters or less, shown in Google results
    description: "YOUR DESCRIPTION (Used for SEO and Excerpt)", // 160 characters or less
    date: "YYYY-MM-DDTHH:mm:ss", // CRITICAL: Use current ISO timestamp (e.g. 2026-02-15T20:30:00)
    authorName: "MyAutoSpex Editorial Team", // Always this byline (see /editorial-policy)
    authorRole: "Car ownership guides",
    category: "Articles & Guides",
    featuredImage: img1, // The main image for the card
    slug: 'your-url-slug', // Must match filename (e.g. my-new-post.tsx -> my-new-post)
};

const MyNewPost: React.FC = () => {
    return (
        <BlogTemplate meta={meta}>
            {/* Do NOT add an <SEO> component: BlogTemplate sets the title and description from `meta`. */}
            {/* Your Content Goes Here */}
            {/* Use standard HTML tags: p, h2, h3, ul, li */}
            {/* Apply these classes for consistency: */}
            {/* - h2: text-3xl font-black tracking-tight text-slate-900 dark:text-white mt-16 mb-8 */}
            {/* - h3: text-2xl font-bold text-slate-900 dark:text-white mt-12 mb-6 */}
            {/* - p: text-slate-600 dark:text-slate-300 mb-6 leading-loose (Template handles line-height usually, but be verbose if needed) */}
            {/* - img/figure: my-14 (Provides good separation from text) */}
            
            {/* Example Image Usage */}
            <figure className="my-14">
                <img src={img1} width={1200} height={800} alt="Description" className="w-full rounded-2xl shadow-lg border border-slate-100 dark:border-slate-800" />
            </figure>

        </BlogTemplate>
    );
};

export default MyNewPost;
```

### 4. Constraints
- **Strict Isolation**: Do NOT modify `routes.tsx`, `App.tsx`, or any other file outside of this new component.
- **Images**: All images must be placed in `/Article/assets/` before referencing them. Assume they are already there if the user provides them.
  - Use WebP files no wider than 1200 px (convert PNG/JPG first; most images end up under 100 KB).
  - Give every `<img>` its real `width` and `height`, and add `loading="lazy"` to every image except the first one.
- **Link to the tools**: Link at least one relevant tool with a plain `<a href="/fault-code-decoder">` style link (tool paths are in `data/tools.ts`). The tool page then lists the article under "Guides for this tool".
- **No invented experience**: Do not write first-person claims of experience ("In my 15 years running a shop..."). Articles are credited to the MyAutoSpex Editorial Team.
- **Sources**: When stating a price, statistic or rule, link to where it comes from (NHTSA, EPA, a state DMV, published pricing data). Leave out figures that have no source.
- **Mobile First**: The `BlogTemplate` handles the outer padding. Ensure any tables or custom grids you create have `overflow-x-auto` to prevent breaking the mobile layout.

### 5. Output
- Return ONLY the full React Component code.
